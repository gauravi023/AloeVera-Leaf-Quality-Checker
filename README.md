# Aloe Vera Leaf Quality Checker

## Project Description

A deep learning based system for detecting Aloe Vera leaf diseases
and classifying leaves into export quality categories.

## Objectives

- Detect common Aloe Vera leaf diseases
- Extract leaf quality features using image processing
- Classify leaves into Grade A, Grade B, or Reject categories
- Provide automated quality evaluation support

## Technologies Used

- Python
- TensorFlow / PyTorch
- OpenCV
- Android Studio
- SQLite
